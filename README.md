# Пятнашки — Telegram Mini App

Готовая веб-версия игры 4×4. В проекте есть счётчик ходов, таймер, локальный рекорд, перемещение мышью/касанием и стрелками клавиатуры, а также базовая интеграция Telegram Web Apps API.

## Запуск локально
Откройте `index.html` в браузере. Для проверки Telegram-интеграции страницу нужно разместить по HTTPS и открыть через Telegram.

## Публикация
1. Загрузите содержимое этой папки в новый GitHub-репозиторий.
2. В GitHub откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
4. Дождитесь адреса вида `https://ВАШ-АККАУНТ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Подключение к боту @nano57484bot
1. Откройте @BotFather и отправьте `/setmenubutton`.
2. Выберите `@nano57484bot`.
3. Укажите название кнопки, например `Играть`.
4. Вставьте HTTPS-адрес GitHub Pages.
5. Откройте бота и нажмите кнопку `Играть`.

Можно также настроить Main Mini App через `/mybots` → выбрать бота → Bot Settings → Configure Mini App.

## Важно
Рекорд хранится локально в браузере пользователя. Для общего рейтинга между всеми игроками нужен сервер и база данных. Telegram `initData` здесь подключён на клиентской стороне для запуска интерфейса, но серверная проверка подписи и авторизация ещё не реализованы.
